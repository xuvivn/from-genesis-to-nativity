# From Genesis to Nativity — 5-Level Storytelling Practice Corpus

English storytelling practice corpus connecting one continuous epic arc across **5 Books (180 Chapters)** unified for **ages 9–10**, following the classic storytelling work of **Jakob Streit** (*And There Was Light*, *Journey to the Promised Land*, *We Will Build a Temple*, *Königskind und Hirtenkind*, *Sankt Nikolaus*).

---

## 5-Level Storytelling Architecture (Level 0 → Level 4)

| Level | Directory | Practice Purpose | Data Scope |
| :--- | :--- | :--- | :--- |
| **Level 0** | [level-0-context/](level-0-context/00-epic-soul-overview.md) | **Context & Soul of the Story** — grasp cultural atmosphere, storytelling rhythm for ages 9–10, pronunciation of ancient names, and supplementary ancient texts before telling. | `00-epic-soul-overview.md` + 5 book guides + [`ancient-texts/`](level-0-context/ancient-texts/) (25 ancient texts) |
| **Level 1** | [level-1-full-text/](level-1-full-text/) | **Full Storytelling Text** — complete read-aloud prose matching the depth and detail of Jakob Streit's work, accompanied by *Storytelling Notes*. | 5 files (`book-1`..`book-5`), covering all **180 Chapters** |
| **Level 2** | [level-2-detailed-outline/](level-2-detailed-outline/) | **Detailed Outlines** — practice telling without the full text while preserving every character, dialogue beat, symbol, and emotional arc. | 5 files (`book-1`..`book-5`), matching all **180 Chapters** |
| **Level 3** | [level-3-summary-outline/](level-3-summary-outline/chapter-summaries.md) | **Condensed Summary Outline** — 1 unified backbone condensing the core plot of every chapter. | 1 file covering all **180 Chapters** |
| **Level 4** | [level-4-visual-prompts/](level-4-visual-prompts/illustration-gallery.md) | **Pure Visual Memory Illustrations** — 28 traditional hand-drawn scenes mapped to Chapter Clusters so storytellers flow freely in their own living words. | `illustration-gallery.md` + shared `../../assets/images/` + `prompts-28-scenes.md` |

## Memory Illustration Styles (Level 4)

- **Illustrations 01–08 (Book I):** Black charcoal paired with warm golden-ochre chalk pastel on ivory fine-art paper, evoking primordial mythic atmosphere through rustic hand-drawn strokes.
- **Illustrations 09–28 (Books II–V):** Monochrome sepia ink and warm umber watercolor wash paired with soft graphite pencil sketching inside a naturally fading vignette on white paper, strictly free of text or digital edges.
- See full artistic prompt specifications in [prompts-28-scenes.md](level-4-visual-prompts/prompts-28-scenes.md).
