# 从创世到圣诞——五阶故事讲述练习语料库

简体中文故事讲述练习语料库（*storytelling practice corpus*），以连贯宏大的史诗脉络串联 **5卷（180章）**，统一面向 **9–10岁** 儿童听众，紧扣 **雅各布·施特赖特（Jakob Streit）** 的经典讲述作品（*And There Was Light*、*Journey to the Promised Land*、*We Will Build a Temple*、*Königskind und Hirtenkind*、*Sankt Nikolaus*）。

---

## 五阶故事讲述训练体系（Level 0 → Level 4）

| 阶次 | 目录 | 训练目的 | 数据范围 |
| :--- | :--- | :--- | :--- |
| **Level 0** | [level-0-context/](level-0-context/00-epic-soul-overview.md) | **故事背景与灵魂** — 把握文化氛围、适合9–10岁听众的讲述节奏、古名读音指南，并在开讲前阅读补充古代文献。 | `00-epic-soul-overview.md` + 5份分卷导读 + [`ancient-texts/`](level-0-context/ancient-texts/)（25部古代文献） |
| **Level 1** | [level-1-full-text/](level-1-full-text/) | **完整故事全文** — 适合朗读的完整叙事文本，媲美施特赖特原著的篇幅与细节，每章附有 *讲演提示*。 | 5份文件（`book-1`..`book-5`），完整涵盖 **180章** |
| **Level 2** | [level-2-detailed-outline/](level-2-detailed-outline/) | **详细故事大纲** — 脱离全文进行讲述练习，同时完整保留人物、对话、象征意象与情感节拍。 | 5份文件（`book-1`..`book-5`），精准对应 **180章** |

## 记忆插画艺术风格（Level 4）

- **第01–08幅（第一卷）：** 象牙艺术纸上的黑色木炭配暖金赭色粉彩，以质朴的手绘素描笔触展现上古创世神话的意境。
- **第09–28幅（第二至五卷）：** 白纸上的古典墨棕与暖褐单色水彩晕染配柔和铅笔素描，构图呈自然晕开的椭圆暗角，不含任何文字或数码锐利痕迹。
- 完整美术提示词规范见 [prompts-28-scenes.md](level-4-visual-prompts/prompts-28-scenes.md)。
